a few rules that keep it sane

  • one muscle memory, two machines: work and personal Macs share the exact same Ctrl+Space Hammerspoon command mode, tmux bindings, and 19 coordinated themes; only app targets and local state differ.
  • stay out of the way: command mode starts off, exits on click or lock, and passes keys straight through to fullscreen games.
  • scrollback over eye candy: both Codex and agy run with alternate-screen disabled so native tmux Ctrl+B [ copy mode and history search always work.
  • reversible everything: every installer writes timestamped local backups before touching a config, and personal machines never mix work credentials or repos.
