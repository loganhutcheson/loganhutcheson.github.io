# loganhutcheson.com

personal portfolio, hosted on GitHub Pages.

- `index.html`: selected work and contact links
- `_posts/`: project notes
- `_layouts/post.html` and `assets/css/site.css`: shared layout
- `resume/`: résumé source; `resume.pdf`: published copy

run `bin/dev` for a local Jekyll preview. pushing `main` publishes through GitHub Pages.
